# Нейронные сети и машинное обучение

Репозиторий с лабораторными работами по дисциплине «Нейронные сети и машинное обучение».

Выполнил: студент группы ИНС-м-о-25-2 Шайдеров Дмитрий Викторович.

## Структура репозитория

Каждая работа организована одинаково:

```text
ЛР_№/
├── datasets/               # исходные данные
│   └── <название_набора>/  # каждый набор в отдельной папке
├── figures/                # рисунки, используемые в отчёте
├── artifacts/              # дополнительные файлы
├── ЛР_№.ipynb              # ноутбук с решением
└── Отчет_ЛР_№              # отчёт по ЛР
```

## Датасеты индивидуальных заданий

| ЛР № | Тема работы | Датасет (ссылка) | Краткое описание |
|---:|---|---|---|
| 1 | Технологии Python | [Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/) | Измерения пингвинов архипелага Палмер для первичного анализа и визуализации данных. |
| 2 | Библиотеки Data Science | [Internet Firewall Data](https://archive.ics.uci.edu/dataset/542/internet+firewall+data) | Записи сетевых соединений для многоклассовой классификации действий межсетевого экрана. |
| 3 | Первичный анализ данных | [Popular Video Games 1980–2023](https://www.kaggle.com/datasets/arnabchaki/popular-video-games-1980-2023) | Каталог видеоигр с рейтингами, жанрами и метриками популярности для первичного анализа. |
| 4 | Линейные модели: метод ближайших соседей | [Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset) | Данные о сне, образе жизни и здоровье для классификации нарушений сна методом kNN. |
| 5 | Линейные модели: регрессия | [Used Phones & Tablets Pricing Dataset](https://www.kaggle.com/datasets/ahsan81/used-handheld-device-data) | Данные о подержанных телефонах и планшетах для регрессионного прогноза цены. |
| 6 | Основы использования библиотеки PyTorch | [HumanVSAI Code Dataset](https://data.mendeley.com/datasets/kjh95n54f8/1) | 10 000 фрагментов кода с метками Human/AI для классификации авторства. |
| 7 | Разработка нейрона на PyTorch | Синтетический набор «Игрушка дьявола» | Синтетический спиральный набор из 300 точек трёх классов для проверки нелинейной разделимости. |
| 8 | Архитектура многослойного персептрона | [CommitSuite](https://github.com/security-pride/CommitSuite) | Сбалансированный набор сообщений коммитов для классификации типов изменений. |
| 9 | Использование многослойного персептрона в задаче классификации | [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist) | Набор изображений одежды 28×28 для классификации десяти классов. |
| 10 | Свёрточная нейронная сеть | [HDL](https://huggingface.co/datasets/gfbati/HDL) | Изображения рукописных логических элементов для классификации восьми классов. |

> Файл `ЛР_9/datasets/fashionmnist/fashion-mnist_train.csv` (>100 МБ) не хранится в Git. Его можно скачать из CSV-версии Fashion-MNIST на [Kaggle](https://www.kaggle.com/datasets/zalando-research/fashionmnist).
